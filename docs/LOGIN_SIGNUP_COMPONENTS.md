# Login and Signup Sources

Implementation combines the selected 2013 Wayback captures for era/copy/layout
with the RobloxLabs WebForms recreation for the matching control hierarchy,
CSS, JavaScript/asset mapping, and legacy class names. The copied RobloxLabs
CSS/images are retained in `wwwroot` to make the source structure render rather
than remain unstyled. Third-party Facebook, advertising, tracking, and TRUSTe
embeds remain excluded.
