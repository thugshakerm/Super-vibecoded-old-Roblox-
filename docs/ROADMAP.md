# Required Platform Roadmap

The project is not limited to website pages. The following backend capabilities
are explicitly required and will be developed as reviewed steps:

1. User/account identity and secure sessions — foundation in progress.
2. Assets, inventory, thumbnails, and private delivery — foundation in progress.
3. Universes, places, immutable place versions — foundation in progress.
4. Private/reserved servers, access permissions, and launch tickets.
5. Per-universe DataStores with quotas, key validation, server-only access, and
   audit/version history.
6. RCC-backed avatar, asset, and place rendering on isolated Windows workers.
7. Groups, roles, catalog, economy, trades, moderation, and creator tools.
8. Historically sourced 2012–2014 pages only after the source gate is satisfied.
