# 2013 Home Dashboard Components

Five source-derived components now preserve the structural sections of the raw
2013 Home capture: Home header, news, best friends, recently played games, and
the two-column dashboard container. Every account-specific field is a runtime
view-model value. Captured username, friends, messages, feed, currency, avatar,
and game history are not used. `BestFriends.css` is copied directly from the
capture; no replacement CSS was authored.
