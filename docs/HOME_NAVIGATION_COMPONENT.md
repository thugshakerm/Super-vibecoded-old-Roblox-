# 2013 Home Navigation Component

The raw Home capture and its companion files are retained in `references/Home/`.
The navigation partial preserves its 2013 hierarchy, labels, classes, route
shape, More dropdown, account-alert placement, and user submenu-compatible
structure. Snapshot-owner username, age marker, currency values, and request
count were replaced with runtime model values; no account snapshot data is
carried into the component.

No new CSS is introduced. The component is not hosted by a page until the
source-derived shared stylesheet and a source-approved Home shell are ready.
